# 헤스랩 v6 검토용 홈페이지

승인된 v5.1 검수 사본을 바탕으로 베이직 70분을 60분으로 수정한 v6입니다.
index.html은 사진·폰트·6개 화면을 포함하는 close 단일 HTML입니다. 비교 페이지는 없습니다.
close는 소스를 바로 읽기 어렵게 만든 Base64 인코딩 전달본입니다. 암호화·완전한 소스 은닉·접근 제어가 아닙니다.
일반 GitHub Pages에서는 공개됩니다. 실제 영업 운영은 정책과 SEO를 고려해 별도 운영 호스팅에 정적 HTML로 적용합니다.
Pretendard SIL OFL 전문을 동봉합니다. 제공 사진·로고·초기 HTML의 사용권은 운영자가 확인합니다.
게시 주소는 저장소 Settings → Pages에 표시되는 실제 배포 URL에서 확인합니다.
